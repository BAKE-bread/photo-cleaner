# 文字搜图

用自然语言查找主体、外观、动作或环境，摄影与绘画可以一起返回。添加多个输入目录，填写描述并搜索，最后勾选候选复制到输出。

怎样写描述
同一个目标的属性写在一行，用顿号或逗号连接，例如“蓝色头发、丸子头、穿小腿袜的人”。“地铁的公共导视图”“蓝天白云、远处雪山”也可直接尝试。

不同目标或同义说法分行写，选“任一条”；希望综合同一目标的多项特征时，可以分行并选“综合全部”。两者都是按相关性排序，属性是否齐全可在预览中确认。

常见视觉描述如“大头照”“绿色系”通常更稳定。知名角色可配外观，例如“初音未来、绿色双马尾”；生僻姓名建议写全名、作品、发色和服装。“学校泳衣”可补充“日式深蓝色连体泳衣 / Japanese school swimsuit”。

可写“头上有装饰”“领结在上衣”等可见关系。数量、否定、细小位置及左右手适合在候选中核对；镜像自拍可优先描述画面位置。结果较少时先保留明显主体与外观，再逐步补充细节。

候选操作
单击图像勾选、双击放大，支持跨页选择。选择输出目录并确认后复制，来源文件保留。可保留层级，扁平输出会复用相同副本，同名不同内容自动编号。搜索时输出目录可先留空。

索引与模型
文字、相似图和风格搜索共用索引。首次建立后支持暂停和后续追加；换描述复用特征。文件改名、移动、分组或新增后更新索引，可按 SHA256 复用兼容特征；修改过的文件单独更新。“缓存与数据库”可查看位置，并把索引复制到其他磁盘或合并兼容索引。

模型：SigLIP 2 Base + DINOv2 Small；精细核对另用 Qwen3-VL-2B，只重排前 60 个候选。模型优先本地加载。默认索引在 .jobs/search，含特征和缩略图，保留它可继续复用。

进阶说明
“任一条”取最高描述相似度；“综合全部”取 50% 平均相似度 + 50% 最低相似度，属于人工指定的排序规则。候选分数用于相对比较。运行期间请让相关目录保持原样。
