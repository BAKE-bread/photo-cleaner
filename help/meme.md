# 表情包

选出反应贴纸、表情图、配字改图、梗图短段子及带明确笑点/反应用途的截图。清晰、大尺寸和反复压缩的表情包都可以入选，判断重点是用途。

普通照片、可爱动物、人物/角色插画、叙事漫画、日常聊天及实体包装图，按整体内容与反应语境综合判断。此页偏向减少误收，边界样本可结合明细复查。

处理条件
最短边默认 0，表示任意静态图像尺寸均可参与。提高表情包入选分数，会缩小结果范围；降低门槛会扩大范围。动图和多帧文件保留原处。

进阶说明
模型组：CLIP ViT-B/32 + Qwen3-VL-2B。先比较反应图和普通图证据，再核对用途、细分类型，按需要补查独立贴纸。CLIP 正负差 d 通过 sigmoid(80d) 映射，与语义证据取几何均值；反应用途核对控制最终分。贴纸补判以贴纸、语义、CLIP 三项几何均值补充原分。

上述融合为人工规则，分数用于候选比较。绘画与设计页复用兼容的表情包证据；两页各自还有类别与门槛条件，结果范围可分别预览。

默认条件：defaults/meme.json。

使用方法
添加一个或多个输入目录，先点“预览”查看结果，再选择输出目录并执行。子目录会一起处理。预览可先留空输出目录，运行中也可打开已完成的明细。

暂停预览后点“继续预览”；暂停执行后点对应的继续按钮。已有兼容分数可用于调整门槛后重筛。图像新增或改变后，用“重新扫描预览”更新范围。

勾选“输出保留来源层级”可保留目录关系；扁平输出将结果放在输出根层，并按文件哈希把相同副本留在原处。选择移到“重复副本备份”后，入选副本进入专用子目录，层级输出也会检查哈希。同名而内容不同的文件自动编号，分别保留。

运行期间请让相关目录保持原样，目录调整可在暂停或完成后进行。保留 .photocleaner 运行记录，便于继续进度、查看报告和恢复本次剪切。

模型与进度
模型优先从本地缓存加载，首次缺少必要文件时可联网补齐。离线选项适用于模型文件已经准备好的环境。自动批量会按设备短测并记住结果；更改目录或门槛时继续复用。CPU 解码线程负责读取与预处理，推理批量控制模型一次处理的数量。设备、显存和预计耗时在进度区显示。

明细与调试
单击表头排序，拖动表头调整列顺序，悬停文件名查看缩略图，双击放大。文件名查找支持跨页定位。

“缩略图复核”按页并列显示图像，与表格共用状态、分组和排序。“门槛影响”先比较已有分数，分别查看新增符合、不再符合和待补算的图片；确认后“应用条件并更新预览”，已有证据继续复用。草稿修改时，原明细和已生成的对比快照各自保留。

“调试选图”支持条件组、逐次筛选、并入或排除结果；点“应用筛选”后生成完整结果视图。Ctrl/Shift、跨页勾选及按条件勾选用于选择样本；“复制选中及指标”复制勾选样本并附上原始指标。

“文件去向”汇总待剪切、复制、回收及保留项。执行按钮会先准备预览，再展示去向与恢复方式，确认后执行。

数值约定
左栏“阈值包含等号”默认采用 ≥ / ≤，可切换为 > / <。实数门槛在使用时取两位小数，整数项按整数输入。简化显示采用四位有效数字、最多六位小数；原始指标用于排序和导出。点击数值输入框可查看真实输入。
