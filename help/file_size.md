# 文件体积筛选

按图像在磁盘上的字节数选择文件，适合把较轻或较大的文件单独整理。输入可为多个目录，子目录和动图一起检查。

组合条件
默认选择 ≤400 KB 或 ≥4 MB。常用写法：
- <400 KB OR >4 MB：选择两个范围。
- >1 MB AND <4 MB：选择中间区间。
- (<100 KB OR >2 MB) AND <10 MB：组合多个范围。

AND 表示同时满足，OR 表示任一满足，括号可组合条件。中文“且/或”同样可用；分号、换行、顿号、逗号和斜线均表示“或”。每个条件包含比较方向、数值和单位。

KB/MB/GB 采用十进制：1 KB = 1000 B，1 MB = 1000000 B。Windows 属性中的某些二进制显示会略有差异。左栏等号开关决定区间边界是否入选，< 与 <= 均按“小于方向”统一处理，> 与 >= 同理。

操作
先预览，再选择输出目录并执行。可保留来源层级，也可扁平输出。扁平输出按哈希把相同副本留在原处；开启副本选项后，符合体积条件的副本进入“重复副本备份”，层级输出也会检查哈希。同名不同内容自动编号。

进阶说明
此页读取文件体积和图像头部信息。修改条件时复用已有证据，新增或更改文件后点“重新扫描预览”。400 KB/4 MB 是可调整的整理起点；图像用途与画质可通过内容筛图进一步判断。

默认条件：defaults/file_size.json。运行期间请让相关目录保持原样。

数值约定
左栏“阈值包含等号”默认采用 ≥ / ≤，可切换为 > / <。实数门槛在使用时取两位小数，整数项按整数输入。简化显示采用四位有效数字、最多六位小数；原始指标用于排序和导出。点击数值输入框可查看真实输入。
