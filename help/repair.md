# 图像兼容修复

检查 Windows 系统解码与文件名，给需要处理的图像补全后缀或生成 PNG 显示副本。原件始终保留。

默认处理
添加输入目录并预览，子目录和无后缀文件一起检查。
- Windows 可解码、文件后缀可用：保留原处。JPEG 内容使用 .png 等情况也按实际解码结果判断。
- 无后缀、.null 等文件：补全可直接打开的后缀，优先复制原编码。
- Windows 解码失败、本软件完整解码成功：静态图像输出普通 PNG。
- 空文件或双方都无法解码的文件：原件保留，明细说明原因。

“为全部输入图像生成 PNG 副本”的范围
勾选后，本次任务会处理输入列表中所有目录及子目录里的可解码静态图像，包含默认判断为可正常打开的图像。像素上限仍生效，已验证的相同副本会复用。明细中的调试勾选仅用于“复制测试图像”，任务生成范围由输入目录与此选项决定。

这适合已知照片应用仍有打开问题、希望统一转换的一批文件。可将这些文件所在的目录加入输入，再启用该选项。

输出与检查
选择输出目录，可保留来源层级。输出保持像素尺寸，校正方向并保留透明部分；重新编码生成普通 8 位 RGB/RGBA PNG，格式专属元数据保存在原件中。Windows 系统会再次检查输出副本，同名文件自动编号。

多帧图像可在保留完整编码时补全后缀；需要重编码的多帧文件保留原处。超过像素上限或 256 帧的文件同样保留。系统检查不可用时明细显示“未检查”。Windows 解码结果与照片应用各有运行环境，强制转换选项可用于处理应用特有问题。

进阶说明
旧版检查缓存会更新，安装编解码器后可用“重新扫描预览”刷新。输出的 .photocleaner/repair 保存记录，defaults/repair.json 保存默认条件。失败时保留原件和暂存副本供核对。运行期间请让相关目录保持原样。
