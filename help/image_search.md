# 以图搜图

添加多个输入目录，选择或拖入参考图，搜索后勾选候选并复制到输出。原图保留，子目录一起参与。

两种方式
“相似或相同”优先返回画面相近的图像，字节完全相同的副本排在前面，参考图自身默认从结果中省略。
“相近风格”适合人物、Cosplay、Kigurumi 和插画系列，综合视觉特征、风格与色彩排序。人物身份、作者或拍摄日期可结合预览确认。

切换两种方式复用同一份索引。文字搜索也使用这份索引，首次建立后可持续追加。

候选操作
单击缩略图勾选，双击放大，支持跨页选择。确认后仅复制勾选候选。输出可保留来源层级；扁平输出复用相同副本，同名不同内容自动编号。缩略图在后台读取，窗口缩放只调整排版。

文件移动、改名、去分组、重新分组或新增后，更新索引可按 SHA256 复用兼容特征。更改过的文件单独更新。索引支持暂停和关闭后续建，可在“缓存与数据库”查看实际位置、复制到其他磁盘或合并兼容索引。

进阶说明
模型：SigLIP 2 Base + DINOv2 Small，优先本地加载。相似图排序使用 85% 图文特征 + 15% 感知哈希相似度；风格排序使用 35% 图文 + 55% DINO + 10% 色彩，并有类别小幅修正。DINO 使用 40% CLS / 60% 平均 patch 拼接。系数为人工指定的排序规则，候选分表示相对相关性。

默认索引在 .jobs/search，保留索引可持续复用。输出可在搜索后选择。运行期间请让相关目录保持原样。
