# 哈希去重

按完整文件 SHA256 查找字节完全相同的文件。先预览保留位置和副本，再确认回收。

原位去重
适合多个目录保持各自结构、只清理重复副本的整理需求。
1. 添加互相独立的输入目录，每个目录的子目录自动参与。
2. 选择“原位去重”。列表上方的目录优先保留，可选中目录后“提高优先级”或“降低优先级”。
3. 预览并查看“原位保留”和“待执行”的文件，确认后点“回收重复副本”。

保留文件和其他独有文件维持原路径，原有目录结构及空目录保留。每组相同内容最终保留一份，其余副本进入回收站。输出目录留空即可。目录内按较短相对路径、再按文件名确定保留项。原位模式处理全部普通文件。

归集去重
适合把主文件集中到一个输出目录。优先保留输出中已有的一份；新内容移动一份到输出，多余副本回收。输出可以作为输入之一。
输出仅作为查重库存时，其已有文件单独显示；把输出目录本身加入输入后，它也参与本轮清理。输出位于输入内部时，仍按是否明确加入输入来决定。

基准去重
适合保留一套现有图库，清理其他目录中与它相同的图像。选中一个输入并点“设为基准目录”，预览后“回收匹配副本”。基准及内部重复图像保持原样；其他输入中匹配基准的副本回收，其余文件留原处。此模式按常见图像后缀检查，大小写均可，输出目录留空即可。

安全与记录
执行前再次核对保留文件与副本。读取范围不完整时，本轮保持文件原位，待目录可用后继续。发生变化或回收失败的文件显示“需复查”。运行期间请让相关目录保持原样。

原位模式直接从原路径送入回收站，恢复时可回到原路径；记录在程序 .jobs/hash_inplace。基准模式记录在 .jobs/hash_std，归集模式记录在输出的 .photocleaner/hash。后两种模式先暂存再回收，回收站恢复到暂存位置，原路径可在 CSV 中查看。

进阶说明
文件编码或元数据改变会改变 SHA256；视觉相似图可使用以图搜图。未变化文件复用哈希；调整原位目录优先级时继续复用已有哈希。符号链接和目录联接保留原处。
